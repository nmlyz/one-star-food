A tiny program that writes a single sentence to `entry.txt`: a one-star review of planet Earth from an alien tourist who still admits the food was excellent.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). The sentence is one line of at most 200 characters, and the program checks that before writing. Running it twice produces byte-identical output.

## Layout

- `main.py` — the program, standard library only.
- `entry.txt` — the sentence it writes (generated, not stored here).
